TORTOISE CREW - ONE-TIME UPDATE

If you already installed the OLD browser-based Tortoise Crew Next launcher
from EXE v1.0.13 and it does not update itself, do this ONCE:

1. CLOSE World of Warcraft and the launcher.
2. Double-click TortoiseCrew-Upgrade.cmd in this folder.
3. A command window will download the official installer from
   machomich123/OctoGuide-downloads, verify the release ZIP via SHA-256,
   preserve the old app and switch your desktop shortcut.
4. Afterwards use the normal Tortoise Crew desktop shortcut. Future
   source updates are checked on GitHub automatically.

If you still have the original EXE launcher and it offers v1.0.14,
use that built-in update instead; no .cmd is needed.

Do not disable Windows Defender or Smart App Control. If Windows refuses
this downloaded script, keep the existing launcher and ask for help.
