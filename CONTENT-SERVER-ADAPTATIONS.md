# OctoWoW content adaptations

The authored Vanilla source is checked against the installed quest facts and official OctoWoW database. Same-title quests are selected by actual giver, hand-in target and chain prerequisite, not title alone. The audit records exact context for each correction.

## Dark Iron Legacy

OctoWoW provides Forgewright's Brazier (object 300421) as a living-accessible starter and hand-in object for quest 3801 and starter for 3802. Both Normal and Hardcore routes use this object at Burning Steppes map projection 29.13, 28.83. The guide does not require becoming a ghost for this chain. The living pickup relationships are verified; the actual interaction still needs an in-game test. The quest page also advertises a brazier hand-in for 3802, but the object reverse index lists only 3801. Because these views conflict, completion follows the explicit 3802 objective: use Ironfel at the Shrine of Thaurissan inside Blackrock Depths. No invented outdoor arrow is shown for that interior hand-in.

Sources: https://octowow.st/db/?quest=3801 , https://octowow.st/db/?quest=3802 , https://octowow.st/db/?object=300421 .

## Videre / Linken

The Videre Elixir is different: its item spell is Quest Suicide (spell 14050, Instakill). The death-dependent ghost section and dependent Linken continuation are excluded from Hardcore. This is not treated like the living-accessible brazier.

Sources: https://octowow.st/db/?item=11243 , https://octowow.st/db/?spell=14050 .
